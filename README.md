使用方法
使用手机摄像头拍摄需要比较的两块屏幕。
将拍摄好的照片放入项目中的 photos 文件夹(需要提前手动创建)。
运行项目中的 .bat 文件，程序会自动读取 photos 中的照片并进行分析。
程序运行完成后会输出两块屏幕之间的颜色差异值，包括 ΔR、ΔG 和 ΔB。
根据差异值对需要调整的屏幕进行小幅调整，然后重新拍摄并运行程序。
重复测量和调整，使各项差异值逐渐接近 0。

例如：

ΔR = +4.49
ΔG = +1.28
ΔB = +1.16

差异值的正负表示对应颜色通道的相对偏差，数值越接近 0，代表两块屏幕在该项目上的颜色差异越小。

建议每次只进行小幅调整，调整后重新拍摄测量，不要一次进行大幅修改。具体调整方向请根据程序输出的差异定义判断。

注意事项

本工具使用手机摄像头进行相对颜色分析，会受到手机摄像头、自动曝光、自动白平衡、环境光、拍摄角度以及屏幕状态等因素影响。

因此，本工具不是专业的色彩校准工具，不会测量屏幕的绝对色域、色温或色彩准确度。它的目的只是通过拍摄和数据对比，帮助用户减小两块屏幕之间的颜色差距。
